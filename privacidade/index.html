Privacidade e LGPD

Resumo: o Lousa não coleta seus dados pessoais. Esta página explica os poucos casos em que alguma informação técnica sai do seu computador.

Última atualização: 12 de novembro de 2026.

1. Quem é o responsável

A OmegaCo Tech Digital é a controladora dos dados tratados neste site e no Lousa, nos termos da Lei Geral de Proteção de Dados (Lei nº 13.709/2018, LGPD).

2. O programa Lousa

O que fica só no seu computador

Suas artes, projetos, modelos, imagens e configurações ficam em pastas ao lado do Lousa.exe (dados, projetos, modelos e imagens). Nós não temos acesso a esses arquivos. O Lousa não pede cadastro, não usa cookies, não exibe anúncios e não rastreia o que você faz.

Verificação de versão nova

Quando o computador está conectado à internet, o Lousa consulta o GitHub para saber se existe uma versão mais recente. Nessa consulta, o GitHub recebe as informações técnicas de qualquer acesso à internet, como o endereço IP. Nenhum dado seu é enviado à OmegaCo Tech Digital.

Registro de erros

Quando acontece um erro, o Lousa grava uma descrição técnica no arquivo dados\erros.log, no seu computador. Esse registro só é enviado para fora se você mesmo configurar o envio automático no arquivo de configuração. Nesse caso, cada erro vira um relato no repositório do GitHub que você indicar, com a mensagem do erro, o ponto do programa onde ele ocorreu, a data e a hora e a identificação técnica do navegador interno. O conteúdo das suas artes não é enviado.

3. Este site

O site é hospedado no GitHub Pages. Como qualquer servidor, o GitHub registra dados técnicos de acesso, como endereço IP, data, hora e página visitada, de acordo com a política de privacidade do GitHub. O site não usa cookies, ferramentas de análise de audiência nem anúncios. As fontes são servidas pelo próprio site.

4. Relatos de problema no GitHub

Se você relatar um problema pelo GitHub, o que escrever ficará público e será tratado também pelo GitHub, conforme os termos dele. Não inclua dados pessoais nesses relatos. Usamos o conteúdo apenas para entender e corrigir o problema.

5. Bases legais

  • Verificação de versão e registro de erros: legítimo interesse em manter o programa seguro e funcionando (art. 7º, IX, da LGPD).
  • Envio automático de erros, quando você o configura: seu consentimento (art. 7º, I).
  • Relatos públicos no GitHub: dados que você mesmo torna públicos, usados para a finalidade com que foram publicados (art. 7º, § 4º).

6. Compartilhamento e transferência internacional

Não vendemos nem alugamos dados. O único terceiro envolvido é o GitHub, Inc., que processa dados nos Estados Unidos. Essa transferência internacional ocorre conforme o art. 33 da LGPD, com base nas garantias contratuais oferecidas pelo GitHub.

7. Por quanto tempo guardamos

A OmegaCo Tech Digital não mantém base de dados de usuários. Relatos de problema permanecem no GitHub enquanto forem úteis para o histórico do projeto. Você pode pedir a remoção a qualquer momento.

8. Seus direitos

Pela LGPD (art. 18), você pode pedir, a qualquer momento:

  • confirmação de que tratamos dados seus e acesso a eles;
  • correção de dados incompletos, inexatos ou desatualizados;
  • anonimização, bloqueio ou eliminação de dados desnecessários ou tratados em desconformidade com a lei;
  • portabilidade dos dados;
  • eliminação dos dados tratados com base no seu consentimento, e revogação desse consentimento;
  • informação sobre com quem compartilhamos seus dados;
  • revisão de decisões tomadas apenas de forma automatizada.

Para exercer qualquer um desses direitos, escreva para leandro.bellizzi@outlook.com. Respondemos em até 15 dias. Você também pode reclamar à Autoridade Nacional de Proteção de Dados (ANPD) em gov.br/anpd.

9. Crianças e adolescentes

O Lousa não coleta dados de ninguém, inclusive de crianças e adolescentes.

10. Mudanças nesta política

Se o Lousa passar a tratar algum dado novo, esta página será atualizada antes da mudança entrar em vigor. A data no topo mostra a versão atual.
